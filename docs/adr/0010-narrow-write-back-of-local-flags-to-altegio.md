# Local client flags may be written back to Altegio, narrowly

Outreach may write a short, tagged line to a client's description in Altegio (for example `[insights] do not contact` or `[insights] win-back: contacted 2026-10-03, no answer`) through a write-back port that only Outreach uses. This narrows ADR-0001 ("never writes back"); it does not reverse it: the CRM Mirror stays strictly read-only, appointments, schedules, prices and every other Altegio field are never written, and a re-import reads the comment back as an ordinary Altegio field. We chose this over keeping `do_not_contact` and outcomes only in `var/` because those flags would be lost with the laptop and invisible to staff who book clients in Altegio. We accepted that comments land in the production CRM and are seen by staff, so only structured, tagged lines are written: flags, outcomes, and the owner's Context about one client (for example `[insights] abroad until 2027-06-01`), never phone numbers or the tool's own opinions of a client, and Context parsing ignores tagged lines so the tool never reads its own writes as new knowledge.
