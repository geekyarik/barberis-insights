# Altegio is the source of truth for facts; the local database is a mirror

Staff keep working in Altegio, and this tool never writes back to it (narrowed by [ADR-0010](0010-narrow-write-back-of-local-flags-to-altegio.md): tagged lines in client descriptions only). Appointments, schedules, clients and prices are imported into a local copy that can be deleted and rebuilt from Altegio at any time. Only data that exists nowhere else — goals, Context factors, win-back cases, hypotheses, playbook tips — needs backing up. We rejected two-way sync because a second place to edit bookings would split the staff's workflow and create conflicts the CRM cannot resolve.
